# Vendored training framework

This directory contains the modified verl framework used by VeriGate. Start with the [project README](../README.md) for installation and training.

The framework retains its original Python import name `verl` for compatibility. Existing source copyright headers, [LICENSE](LICENSE), and [Notice.txt](Notice.txt) are preserved. See [third-party notices](../THIRD_PARTY_NOTICES.md).
